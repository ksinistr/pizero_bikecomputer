# Наложение «где я уже ездил» для Locus Map

Наложение — это файл `rides/ridden_overlay.mbtiles`. В нём прозрачные PNG-тайлы, на которых нарисованы все треки из `rides/gpx/`. В Locus Map его кладут поверх любой базовой карты: так видно, какие дороги уже проезжены, а какие ещё нет.

Файл содержит ваши треки, то есть показывает, где вы живёте и ездите. Он лежит в `rides/`, а эта папка в `.gitignore`. Не публикуйте его.

## 1. Собрать наложение

Если в `rides/gpx/` появились новые GPX, сначала пересоберите слой треков:

```bash
make ridden-roads
```

Затем отрисуйте наложение:

```bash
make locus-overlay
```

Результат — `rides/ridden_overlay.mbtiles`. Для 220 поездок это около 37 МБ и 6 700 тайлов на масштабах 8–16; отрисовка занимает около 4–5 минут.

Параметры:

- `COLOR=E0007A` — цвет линий в HEX без `#`. Малиновый хорошо виден на большинстве карт.
- `OVERLAY_ZOOMS=8-16` — диапазон масштабов. При сильном приближении Locus растягивает тайлы z16, поэтому строить z17–18 обычно не нужно.

```bash
make locus-overlay COLOR=0050FF OVERLAY_ZOOMS=10-16
```

## 2. Перенести файл на телефон

Любой способ, которым файл попадает в память телефона:

- USB-кабель: скопируйте файл в папку `Download` на телефоне;
- облако или мессенджер: отправьте файл себе и сохраните;
- `adb` (если включена отладка по USB):

```bash
adb push rides/ridden_overlay.mbtiles /sdcard/Download/
```

## 3. Добавить файл в Locus Map

Файл добавляется как обычная офлайн-карта.

1. Откройте **Map manager** (менеджер карт) → вкладка **Offline**.
2. Нажмите **+** и выберите импорт файла (**Import** / **External maps**), затем укажите `ridden_overlay.mbtiles` из папки `Download`.
   - Другой путь: откройте файл в файловом менеджере телефона и выберите в списке приложений Locus Map.
3. Карта появится в списке офлайн-карт как **Ridden roads**.

Если Locus предложит «Selected map out of current view. Center?», ответьте **Yes**: карта покрывает только места ваших поездок.

Названия пунктов меню взяты из документации Locus и могут немного отличаться в вашей версии приложения.

## 4. Включить как наложение (нужен Premium)

Наложение карт в Locus Map 4 доступно только с Premium.

1. Выберите обычную базовую карту, например OpenAndroMaps Cyprus или любую онлайн-карту.
2. Откройте **Content panel** (панель содержимого) → **Map overlays**.
3. Включите наложение и выберите в списке **Ridden roads**. Если в списке недавних карт его нет, откройте полный список через ссылку на Map manager.
4. Ползунком **Transparency** настройте прозрачность. Для толстых малиновых линий подходит 20–40 %.
5. В расширенных настройках оставьте **Zooms** со всеми масштабами и **Blend mode** выключенным.

Выключить наложение: переключатель наложения или кнопка с глазом в Content panel.

## 5. Обновить после новых поездок

1. Положите новые GPX в `rides/gpx/` (например, скачанные из intervals.icu).
2. Выполните `make ridden-roads` и `make locus-overlay`.
3. Замените файл на телефоне. Если Locus продолжает показывать старые линии, удалите карту из Map manager и добавьте заново: приложение кэширует тайлы.

## Без Premium

Без Premium наложение карт недоступно. Тогда треки можно импортировать как обычные треки (**Import** в Locus, выбрать GPX-файлы из `rides/gpx/`). Они будут видны поверх любой карты, но 220 отдельных треков загромождают список и медленнее отрисовываются, чем один слой тайлов.
